## 1. 技术总览

### 1.1 技术栈

| 层级 | 技术选型 | 版本 | 说明 |
|------|---------|------|------|
| 语言 | TypeScript | 5.x | strict 模式，全量类型安全 |
| 渲染引擎 | Spark + Three.js | @sparkjsdev/spark 2.x | WebGL2 渲染，Three.js 集成 |
| 渲染引擎（规划） | SuperSplat 核心 | — | WebGPU GPU Radix Sort 渐进增强 |
| 构建工具 | Vite | 5.x | 开发服务器 + 生产构建 |
| 包管理 | pnpm | 9.x | Monorepo workspace |
| 框架适配 | React 18+ / Vue 3 | — | 薄适配层，各约 100 行 |
| 排序引擎 | Rust → WASM Worker | — | Spark 内置，SharedArrayBuffer 通信 |
| 数据格式 | SPZ / .splat / .ply / SOG | — | 多格式支持，SPZ 首选 |

### 1.2 核心设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 是否自研渲染引擎 | **否**，复用 Spark + SuperSplat | 投入产出比极低，开源方案性能已远超需求 |
| 渲染后端策略 | **WebGL2 为主 + WebGPU 渐进增强** | iOS Safari WebGPU 覆盖率低，WebGL2 保底必需 |
| 核心差异化 | **漫游框架**（场景图 + 热点 + 配置 + 插件） | 竞品的核心价值在漫游、交互、拓展能力而非渲染本身 |
| 架构模式 | **Monorepo + 五层解耦** | 关注点分离，可替换性，渐进增强 |
| 像素比策略 | **固定 1.0**（不跟随 DPR） | DPR=2 时片段着色器开销 4×，3DGS 不需要 |
| 抗锯齿策略 | **关闭 MSAA** | 3DGS 的 alpha blending 不需要 MSAA，开启反而降帧 |
| 帧循环策略 | **单一 RAF** | 杜绝双 RAF 导致的冗余工作和调度冲突 |

[来源: 项目源码 — `packages/renderer-three/src/index.ts:302-306`；Spark 官方文档 `sparkjs.dev`]

```

@3dgs/plugins ────┘    @3dgs/renderer-three
```

**关键约束**：
- `@3dgs/core` 零运行时 npm 依赖，仅导出类型和接口
- `@3dgs/renderer-three` 依赖 `@3dgs/core`（仅类型）、`three`、`@sparkjsdev/spark`（均作为 peerDependency）
- `@3dgs/plugins` 依赖 `@3dgs/core`（仅类型）
- `@3dgs/react` / `@3dgs/vue` 依赖 `@3dgs/core`（peer），不直接依赖渲染器

[来源: 项目源码 — `packages/core/src/index.ts:1-6`；`packages/renderer-three/src/index.ts:22-27`]

### 2.4 设计原则

| 原则 | 实现方式 | 源码位置 |
|------|---------|---------|
| **渲染解耦** | `RendererAdapter` 接口抽象渲染后端，核心层不依赖 Three.js | `core/src/renderer-adapter.ts` |
| **热点解耦** | 热点逻辑完全在 `@3dgs/plugins/hotspot`，核心层不感知 | `plugins/src/hotspot/index.ts` |
| **配置解耦** | `SceneConfig.extensions` 通用扩展点，核心层不感知插件配置 schema | `core/src/tour-config.ts:52-57` |
| **零运行时依赖** | 核心包仅导出类型和接口，无 npm 运行时依赖 | `core/src/index.ts` |
| **可替换性** | 渲染后端可替换（实现 `RendererAdapter` 即可） | `core/src/renderer-adapter.ts` |
| **渐进增强** | WebGL2 保底 + WebGPU 规划中 | `renderer-three/src/index.ts` |

## 3. 核心框架层设计

### 3.1 TourPlayer — 核心编排器

`TourPlayer` 是整个框架的中枢，负责帧循环管理、场景切换、插件编排和事件总线。

[来源: 项目源码 — `packages/core/src/tour-player.ts`]

#### 职责

| 职责 | 说明 |
|------|------|
| 帧循环管理 | 通过 `renderer.onFrame()` 挂载到渲染器的单一 RAF 循环 |
| 场景切换 | 委托 `SceneManager` 管理场景状态，委托 `RendererAdapter` 加载渲染数据 |
| 插件编排 | 通过 `PluginSystem` 管理插件生命周期和每帧更新 |
| 事件总线 | `on()` / `emit()` 公开化，供插件间通信 |

#### 关键设计：单一 RAF 循环

```typescript
// [来源: packages/core/src/tour-player.ts:70-74]
// ★ 通过 onFrame 回调挂载到渲染器的单一 RAF 循环
// 不再创建独立的 RAF 循环
this._frameUnsub = this.renderer?.onFrame((dt) => {
  this.onFrame(dt);
});
```

**为什么不用独立 RAF？** 两个独立的 `requestAnimationFrame` 循环会导致：
- 每帧额外 1-2ms 调度开销
- 两个循环的时序不确定，可能导致热点位置与渲染画面不同步
- GC 压力增大

#### 关键设计：emit 公开化

```typescript
// [来源: packages/core/src/tour-player.ts:127-135]
/** 触发事件（供插件间通信使用） */
emit(type: string, data?: unknown): void {
  this.listeners.get(type)?.forEach((h) => {
    try { h(data); } catch { /* 安全 */ }
  });
}
```

`emit()` 方法公开化使得插件可以：
- 热点插件派发 `hotspot:click` 事件，UI 层监听
- 热点插件派发 `error` 事件，通知加载失败
- 插件间通过事件总线松耦合通信

#### 每帧回调流程

```typescript
// [来源: packages/core/src/tour-player.ts:101-115]
private onFrame(deltaTime: number): void {
  if (!this.renderer || !this._loaded) return;

  // 1. 从渲染器获取当前帧的相机和视口数据
  const cam = this.renderer.getCameraPosition();
  const vp = this.renderer.getViewProjectionMatrix();
  const size = this.renderer.getSize();

  // 2. 分发给所有插件的 update()
  this.plugins.update(deltaTime, {
    camera: cam,
    vpMatrix: vp,
    size,
    sceneManager: this.sceneManager,
  });
}
```

#### 生命周期

```
new TourPlayer(container)
    │
    ├── setRenderer(renderer)      // 挂载渲染器到 DOM
    ├── use(plugin)                // 注册插件 (可链式调用)
    │
    ├── load(config)               // 加载配置 → 启动渲染 → 注册 onFrame
    │   ├── TourLoader.load(url) | fromObject(obj)
    │   ├── validateTourConfig()
    │   ├── SceneManager.register()  (所有场景)
    │   ├── renderer.start()
    │   └── renderer.onFrame() → this.onFrame
    │
    ├── switchScene(id)            // 切换场景
    │   ├── sceneManager.switchTo()
    │   ├── renderer.loadScene(source)
    │   └── emit('scene:switched')  → 插件监听
    │
    └── destroy()                  // 销毁
        ├── _frameUnsub()           (取消 onFrame)
        ├── plugins.destroyAll()
        ├── renderer.destroy()
        ├── loader.abort()
        └── sceneManager.destroy()
```

### 3.2 RendererAdapter — 渲染器抽象接口

[来源: 项目源码 — `packages/core/src/renderer-adapter.ts`]

```typescript
export interface RendererAdapter {
  mount(container: HTMLElement): void;           // 挂载到 DOM
  start(): void;                                  // 启动渲染 (单一 RAF)
  stop(): void;                                   // 停止渲染
  loadScene(source: string, options?: LoadOptions): Promise<void>;  // 加载场景
  getViewProjectionMatrix(): Float32Array;        // 视图投影矩阵 (16元素)
  getCameraPosition(): { x: number; y: number; z: number };  // 相机世界坐标
  getSize(): { width: number; height: number };   // 视口尺寸
  getDeviceTier(): DeviceTier;                    // 设备分级
  setResolutionScale(scale: number): void;        // 设置分辨率缩放
  onFrame(callback: (deltaTime: number) => void): () => void;  // 注册帧回调
  destroy(): void;                                // 销毁释放 GPU 资源
}
```

**设计要点**：
- `onFrame()` 返回取消注册函数，支持动态挂载/卸载帧回调
- `getViewProjectionMatrix()` 返回 `Float32Array(16)`，供热点插件做 3D→2D 投影
- `DeviceTier` 枚举（LOW / MEDIUM / HIGH / ULTRA）决定渲染参数

```typescript
// [来源: packages/core/src/renderer-adapter.ts:12-17]
export enum DeviceTier {
  LOW,     // 250K splats, 0.5x 分辨率, SH 0
  MEDIUM,  // 500K splats, 0.75x 分辨率, SH 0
  HIGH,    // 1M splats, 1.0x 分辨率, SH 1
  ULTRA,   // 2M+ splats, 1.0x 分辨率, SH 2
}
```

```typescript
const loop = () => {
  if (!this._running || this._destroyed) return;

  const now = performance.now();
  const rawDt = now - lastTime;
  lastTime = now;

  // ★ dt 平滑 (指数移动平均, 过滤单帧尖峰)
  this._smoothDt = this._smoothDt * 0.9 + rawDt * 0.1;
  const dt = Math.min(this._smoothDt, 50);  // 上限 50ms 防卡顿

  // 1. 键盘移动 (在 controls.update 前应用)
  this.applyKeyboardMovement(dt);

  // 2. 控制器更新 (阻尼旋转)
  controls.update();

  // 3. 渲染
  renderer.render(scene, camera);

  // 4. 更新矩阵缓存 (供热点插件使用)
  this.tmpM4.multiplyMatrices(camera.projectionMatrix, camera.matrixWorldInverse);
  this.tmpM4.toArray(this.vpMatrix);
  camera.getWorldPosition(this.tmpV3);
  this.camPos.x = this.tmpV3.x;
  this.camPos.y = this.tmpV3.y;
  this.camPos.z = this.tmpV3.z;

  // 5. 帧回调分发 (TourPlayer/插件挂载于此)
  for (const cb of this.frameCallbacks) {
    try { cb(dt); } catch { /* 安全 */ }
  }

  // 6. 自适应分辨率采样
  this.adaptive?.sample();

  this.rafId = requestAnimationFrame(loop);
};
```

```typescript
private positionCameraToBounds(mesh: SplatMesh): void {
  // 1. 获取世界空间包围盒 (考虑 rotation)
  mesh.updateMatrixWorld();
  const localBox = mesh.getBoundingBox(true);
  const worldBox = localBox.clone().applyMatrix4(mesh.matrixWorld);

  // 2. 计算中心和尺寸
  const center = new THREE.Vector3();
  worldBox.getCenter(center);
  const size = new THREE.Vector3();
  worldBox.getSize(size);
  const maxDim = Math.max(size.x, size.y, size.z);

  // 3. 摄像机放在场景中心, 水平面朝向
  this.camera.position.set(center.x, center.y, center.z);
  this.controls.lookAt(center.x, center.y, center.z - 1);

  // 4. 更新裁剪面
  this.camera.far = Math.max(maxDim * 10, 1000);
  this.camera.near = Math.max(maxDim * 0.001, 0.01);

  // 5. ★ 场景大小自适应移动速度
  this._moveSpeed = Math.max(maxDim * 0.06, 5.0);
  this._verticalSpeed = Math.max(maxDim * 0.04, 3.0);
  this.controls.setWheelSpeed(Math.max(maxDim * 0.005, 0.5));
}
```

### 4.6 自适应分辨率

[来源: 项目源码 — `packages/renderer-three/src/adaptive-resolution.ts`]

```typescript
export class AdaptiveResolution {
  private opts = {
    minFps: 40,          // 低于此帧率 → 降低分辨率
    targetFps: 55,       // 高于此帧率 → 尝试恢复分辨率
    minScale: 0.4,       // 最低分辨率缩放比
    maxScale: 1.0,       // 最高分辨率缩放比
    adjustInterval: 60,  // 调整间隔 (~1秒)
    step: 0.1,           // 每次调整步长
  };

  sample(): void {
    // 每帧采样 FPS
    this.fpsSamples.push(1000 / dt);

    // 每 60 帧调整一次
    if (this.frameCount >= 60) {
      const avgFps = average(this.fpsSamples);
      if (avgFps < minFps) this.lowerResolution();
      if (avgFps > targetFps) this.raiseResolution();
    }
  }
}
```

**工作原理**：
1. 每帧采样 `1000 / deltaTime` 作为瞬时 FPS
2. 每 60 帧（约 1 秒）计算平均 FPS
3. 平均 FPS < 40 → 降低分辨率（步长 0.1，下限 0.4）
4. 平均 FPS > 55 → 尝试恢复分辨率（步长 0.1，上限 1.0）
5. 分辨率变化通过回调通知 `RenderManager` 更新 `spark.renderSize`

```typescript
updateVisibility(data: HotspotUpdateData): void {
  const { camera, vpMatrix, width, height } = data;

  for (const instance of this.hotspots.values()) {
    const [px, py, pz] = instance.config.position;

    // ── 3D → Clip Space ──
    // VP 矩阵 (4×4, column-major) × position(x, y, z, 1)
    const clipX = vpMatrix[0]*px + vpMatrix[4]*py + vpMatrix[8] *pz + vpMatrix[12];
    const clipY = vpMatrix[1]*px + vpMatrix[5]*py + vpMatrix[9] *pz + vpMatrix[13];
    const clipZ = vpMatrix[2]*px + vpMatrix[6]*py + vpMatrix[10]*pz + vpMatrix[14];
    const clipW = vpMatrix[3]*px + vpMatrix[7]*py + vpMatrix[11]*pz + vpMatrix[15];

    // ── 相机后方剔除 ──
    if (clipW <= 0) { hide(instance); continue; }

    // ── NDC ──
    const ndcX = clipX / clipW;
    const ndcY = clipY / clipW;
    const ndcZ = clipZ / clipW;

    // ── 屏幕坐标 ──
    const screenX = (ndcX * 0.5 + 0.5) * width;
    const screenY = (1.0 - (ndcY * 0.5 + 0.5)) * height;  // Y 翻转

    // ── 视锥体 + 距离过滤 ──
    const inFrustum = ndcZ >= -1 && ndcZ <= 1
                   && ndcX >= -1 && ndcX <= 1
                   && ndcY >= -1 && ndcY <= 1;
    const distance = Math.sqrt(dx*dx + dy*dy + dz*dz);
    const visible = inFrustum && minDistOk && maxDistOk;

    // ── 更新 DOM ──
    if (visible) {
      el.style.left = `${screenX}px`;
      el.style.top = `${screenY}px`;
      el.style.opacity = String(distanceAttenuation);
    }
  }
}
```

### 6.1 DragLookControls — 拖拽式视角控制

[来源: 项目源码 — `packages/renderer-three/src/index.ts:65-205`]

#### 设计动机

| 控制方式 | 行为 | 适合场景 |
|---------|------|---------|
| OrbitControls | 相机绕 target 点做球面运动（有视差） | 物体查看（查看外部） |
| **DragLookControls** | 相机原地旋转（无视差，像转头） | **全景漫游（查看内部）** |

OrbitControls 在漫游时产生不自然的视差效果——拖拽时场景中近处物体比远处移动更多，不符合"站在原地转头"的直觉。DragLookControls 模拟人头转动，提供 Krpano 级别的漫游体验。

#### 实现原理

```typescript
class DragLookControls {
  // Euler 角 (YXZ 顺序: yaw, pitch, roll)
  private _euler = new THREE.Euler(0, 0, 0, 'YXZ');
  private _targetEuler = new THREE.Euler(0, 0, 0, 'YXZ');

  // 指针事件 → 目标 Euler 角
  this._onPointerMove = (e) => {
    const dx = e.clientX - this._lastX;
    const dy = e.clientY - this._lastY;

    // ★ 全景拖拽方向: 场景跟随鼠标移动
    //   鼠标向右拖 → 场景向右移 → 相机向左转 (yaw+)
    //   鼠标向下拖 → 场景向下移 → 相机向上看 (pitch+)
    this._targetEuler.y += dx * this.rotateSpeed;   // yaw
    this._targetEuler.x += dy * this.rotateSpeed;   // pitch

    // 限制 pitch 避免 gimbal lock
    const limit = Math.PI / 2 - 0.05;
    this._targetEuler.x = clamp(this._targetEuler.x, -limit, limit);
  };

  // 滚轮 → 沿视线方向前进/后退
  this._onWheel = (e) => {
    e.preventDefault();
    this._tmpForward.set(0, 0, -1).applyEuler(this._euler);
    this.camera.position.addScaledVector(
      this._tmpForward,
      -e.deltaY * this.wheelSpeed * 0.01
    );
  };

  // 每帧更新: 阻尼插值
  update(): void {
    if (this.enableDamping) {
      this._euler.x += (this._targetEuler.x - this._euler.x) * this.dampingFactor;
      this._euler.y += (this._targetEuler.y - this._euler.y) * this.dampingFactor;
    }
    this.camera.quaternion.setFromEuler(this._euler);
  }
}
```

#### 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rotateSpeed` | 0.003 弧度/像素 | 拖拽旋转灵敏度 |
| `wheelSpeed` | 0.5 | 滚轮移动速度（场景自适应） |
| `dampingFactor` | 0.12 | 阻尼系数（越大越灵敏） |
| pitch 限制 | ±(π/2 - 0.05) | 避免 gimbal lock |

#### YXZ Euler 顺序

使用 `YXZ` 顺序而非默认的 `XYZ`：
- **Y（yaw）**：首先应用，水平转头
- **X（pitch）**：其次应用，上下看
- **Z（roll）**：最后应用，始终为 0

这确保了 pitch 不会影响 yaw 轴的方向，避免了 gimbal lock 问题。

### 6.2 键盘自由漫游

[来源: 项目源码 — `packages/renderer-three/src/index.ts:710-769`]

#### 连续指数平滑

```typescript
private applyKeyboardMovement(dtMs: number): void {
  const dt = dtMs / 1000;

  // 1. 计算目标速度 (本地空间)
  this._targetVel.set(0, 0, 0);
  if (keys.has('w')) this._targetVel.z -= this._moveSpeed;  // 前进
  if (keys.has('s')) this._targetVel.z += this._moveSpeed;  // 后退
  if (keys.has('a')) this._targetVel.x -= this._moveSpeed;  // 左移
  if (keys.has('d')) this._targetVel.x += this._moveSpeed;  // 右移
  if (keys.has('q')) this._targetVel.y += this._verticalSpeed;  // 升
  if (keys.has('e')) this._targetVel.y -= this._verticalSpeed;  // 降

  // 2. ★ 连续指数平滑 (帧率无关)
  // alpha = 1 - exp(-dt / τ)
  // τ = 0.08s: 约 80ms 达到 63% 目标速度, 约 240ms 达到 95%
  const alpha = 1 - Math.exp(-dt / MOVE_TIME_CONSTANT);
  this._currentVel.lerp(this._targetVel, alpha);

  // 3. 本地空间平移 (自动跟随相机朝向)
  this.camera.translateX(this._currentVel.x * dt);
  this.camera.translateY(this._currentVel.y * dt);
  this.camera.translateZ(this._currentVel.z * dt);
}
```

#### 为什么用 `exp(-dt/τ)` 而非固定步长？

| 方案 | 公式 | 问题 |
|------|------|------|
| 固定步长累加器 | `accumulator += dt; while (acc >= step) { move(); acc -= step; }` | 物理更新与渲染不同步，量化伪影导致跳变 |
| 离散帧计数近似 | `alpha = 1 - Math.pow(1 - s, dt * 60)` | 不同帧率下有微小误差 |
| **连续指数平滑** | `alpha = 1 - Math.exp(-dt / τ)` | **任意 dt 下数学精确等价，帧率无关** |

[来源: Frame-rate independent damping — `gamedeveloper.com/programming/frame-rate-independent-damping`]

#### 本地空间平移

使用 `camera.translateX/Y/Z` 而非手动计算方向向量：
- 自动使用相机本地坐标系，无需每帧 `getWorldDirection + crossVectors + normalize`
- 消除方向向量微变导致的位移抖动
- `translateY` 依赖相机 up 向量 = 世界 Y 轴（DragLookControls 的 YXZ Euler 保证）

#### 速度自适应

场景加载后，根据包围盒大小自动调整移动速度：

```typescript
// [来源: packages/renderer-three/src/index.ts:586-590]
this._moveSpeed = Math.max(maxDim * 0.06, 5.0);      // 每秒移动场景最大维度的 6%
this._verticalSpeed = Math.max(maxDim * 0.04, 3.0);   // 升降速度
this.controls.setWheelSpeed(Math.max(maxDim * 0.005, 0.5));  // 滚轮速度
```

## 9. 框架适配层设计

### 9.1 React 适配层

[来源: 项目源码 — `packages/react/src/index.tsx`]

```typescript
export function TourViewer({ config, renderer, plugins, ...callbacks }: TourViewerProps) {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const player = new TourPlayer(containerRef.current!);

    // 挂载渲染器
    const r = typeof renderer === 'function' ? renderer() : renderer;
    player.setRenderer(r);

    // 注册插件
    plugins?.forEach((p) => player.use(p));

    // 事件订阅
    const unsubs: (() => void)[] = [];
    unsubs.push(player.on('load', (data) => { onLoad?.(data); /* 初始场景 */ }));
    unsubs.push(player.on('scene:switched', (data) => onSceneSwitch?.(data.sceneId)));
    unsubs.push(player.on('hotspot:click', (data) => onHotspotClick?.(data.id)));
    unsubs.push(player.on('error', (data) => onError?.(data.message)));

    // 加载配置
    player.load(config).catch((err) => setErrorSafe(err.message));

    // 清理
    return () => {
      unsubs.forEach((fn) => fn());
      player.destroy();
    };
  }, [config, renderer, plugins, ...]);

  return <div ref={containerRef} style={{ width: '100%', height: '100%' }} />;
}
```

**设计要点**：
- `useEffect` 返回清理函数，组件卸载时调用 `player.destroy()`
- 事件订阅返回取消函数，存入 `unsubs` 数组统一清理
- `renderer` 支持实例或工厂函数（工厂函数避免实例在 re-render 时重复创建）
- 错误状态用 React state 管理，渲染错误提示 UI

### 9.2 Vue 适配层

[来源: 项目源码 — `packages/vue/src/index.ts`]

```typescript
export const TourViewer = defineComponent({
  props: {
    config: { type: [String, Object] as PropType<string | TourConfig>, required: true },
    renderer: { type: [Object, Function], required: true },
    plugins: { type: Array as PropType<TourPlugin[]>, default: () => [] },
  },
  emits: ['load', 'scene-switch', 'hotspot-click', 'error'],
  setup(props, { emit, expose }) {
    const containerRef = ref<HTMLElement | null>(null);
    let player: TourPlayer | null = null;

    onMounted(() => {
      player = new TourPlayer(containerRef.value!);
      player.setRenderer(/* ... */);
      props.plugins.forEach((p) => player!.use(p));

      player.on('load', (data) => emit('load', data));
      player.on('scene:switched', (data) => emit('scene-switch', data.sceneId));
      // ...

      loadConfig(props.config);
    });

    onUnmounted(() => player?.destroy());

    watch(() => props.config, (cfg) => loadConfig(cfg));

    expose({ getPlayer: () => player });

    return () => h('div', { ref: containerRef, /* ... */ });
  },
});
```

**设计要点**：
- `onMounted` / `onUnmounted` 管理生命周期
- `watch` 监听 config 变化，支持动态切换漫游配置
- `expose` 暴露 `getPlayer()` 供父组件通过 ref 访问底层 API
- `h()` 渲染函数（非 template），避免模板编译开销

## 12. 错误处理与容错策略

### 12.1 错误处理层级

| 层级 | 错误类型 | 处理方式 | 源码位置 |
|------|---------|---------|---------|
| 配置加载 | URL fetch 失败 | `emit('error')` + throw | `tour-loader.ts:31-33` |
| 配置验证 | schema 不合法 | `TourConfigValidationError` | `tour-config.ts:98-103` |
| 场景加载 | source 为空 | reject + `emit('error')` | `renderer-three/src/index.ts:454-456` |
| 场景加载 | splat 文件加载失败 | onLoad 回调错误 | `renderer-three/src/index.ts:425-457` |
| 摄像机定位 | getBoundingBox 失败 | console.warn + 降级 | `renderer-three/src/index.ts:598-600` |
| LOD 构建 | createLodSplats 失败 | console.warn + 不影响渲染 | `renderer-three/src/index.ts:623-626` |
| 插件异常 | init/update/throw | try-catch 安全包裹 | `plugin-system.ts:64,72-74` |
| 帧回调异常 | onFrame throw | try-catch 安全包裹 | `renderer-three/src/index.ts:382-385` |
| 事件处理异常 | handler throw | try-catch 安全包裹 | `tour-player.ts:129-131` |

### 12.2 容错原则

1. **插件异常不影响主循环**：所有 `plugin.update()` 调用包裹在 try-catch 中
2. **帧回调异常不影响渲染**：所有 `onFrame` 回调包裹在 try-catch 中
3. **事件处理异常不影响其他监听器**：每个 handler 独立 try-catch
4. **LOD 失败不阻断渲染**：LOD 是优化，非必需功能
5. **摄像机定位失败使用降级方案**：console.warn 后继续
